# Reviewer checklist

- [ ] Every new or changed fact is supported by the linked official source.
- [ ] Title, identifier, issuing authority, dates, applicability, and status match the source.
- [ ] Authority level does not overstate guidance as binding.
- [ ] Deadlines include scope, date, and current/historical context.
- [ ] Previous/proposed values and withdrawals are understandable.
- [ ] Every Zero Trust excerpt is exact, explicit, located, and programmatically verified.
- [ ] Superseded/rescinded relationships are reciprocal where appropriate.
- [ ] No duplicate identifier or unofficial URL was introduced.
- [ ] Token/cost estimate is plausible at current OpenRouter prices.
- [ ] Tests, source checks, schema validation, and build pass before merge.
